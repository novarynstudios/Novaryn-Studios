## About Novaryn Studios

**Novaryn Studios** is a software development studio focused on building polished, practical, and performance-oriented products for Minecraft servers, online communities, and modern web platforms.

We work on everything from lightweight server utilities to advanced practice-server systems, Discord integrations, automation tools, APIs, dashboards, and interactive websites.

Our goal is simple:

> Build software that feels production-ready, performs reliably, and is actually useful.

---

## What We Build

### Minecraft Development

We build custom plugins, addons, server utilities, integrations, and backend systems for modern Minecraft networks.

Our work includes:

- Paper, Purpur, Spigot, and Bukkit plugins
- StrikePractice addons and integrations
- PvP and practice-server systems
- Queue and matchmaking systems
- Server-core utilities
- Cross-server and proxy integrations
- Velocity-based network systems
- PlaceholderAPI integrations
- Discord integrations
- Licensing and resource-delivery systems
- Performance and server-management tooling

## Featured Projects

### Novaryn Announcer

A flexible Minecraft announcement system designed for servers that need more than basic scheduled chat messages.

Features include:

- Chat announcements
- Action bars
- Titles
- Boss bars
- Sounds
- Ordered, random, and weighted rotations
- Click and hover events
- PlaceholderAPI support
- Advanced player targeting
- Per-player controls

---

### Novaryn Queue Bar

A StrikePractice addon that improves queue feedback with a clean action-bar interface.

Designed to display information such as:

- Selected kit
- Ranked / unranked state
- Queue duration
- Players in queue
- Kit-specific formatting
- Player toggle controls

## Development Principles

We aim to keep our projects:

**Reliable**  
Software should behave predictably in real-world environments.

**Maintainable**  
Clean architecture and sensible project structure matter after the first release.

**Performant**  
Server software should avoid unnecessary overhead and scale appropriately.

**Configurable**  
Administrators should be able to adapt products without rewriting code.

**User-focused**  
Features should solve real problems instead of existing only for a feature list.
